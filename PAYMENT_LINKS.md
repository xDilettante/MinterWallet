# Платёжные ссылки MinterWallet 0.8.6

Windows и Android открывают `minterwallet://pay/tx/<base64url-RLP>`.
Внутри — стандартный Minter Link: Send, положительная сумма, без payload,
пароля, query и fragment. Остальные типы операций по внешней ссылке запрещены.
Для ручной вставки по-прежнему поддерживается стандартный `https://bip.to/tx/…`.

- Android: ACTION_VIEW, BROWSABLE/DEFAULT, схема `minterwallet`, host `pay`,
  prefix `/tx/`; холодный запуск и OnNewIntent передают запрос общему Shell.
- Windows: обычный запуск portable EXE регистрирует только свою схему в HKCU,
  без прав администратора. `--data` не меняет регистрацию. Повторный запуск
  передаёт запрос существующему процессу через same-user named pipe.
- Linux: deb/AppImage desktop entry объявляет x-scheme-handler/minterwallet
  и передаёт URI аргументом `%u`. Доступность зависит от интеграции пакета
  в desktop environment; отдельный голый binary сам схему не регистрирует.

Запрос ждёт разблокировки только в памяти и заполняет экран «Перевод».
Подпись, подтверждение пользователя, пароль/биометрия, проверка сети и отправка
не вызываются ссылкой. Во время активной отправки новый запрос отклоняется.
Предыдущая версия 0.8.5 умеет вставлять стандартную ссылку в поле получателя,
но не запускается напрямую по новой схеме.

Для сайтов и мессенджеров можно использовать HTTPS-страницу со ссылкой
`minterwallet://pay/tx/…`. Страница показывает реквизиты и открывает приложение;
проверка получателя, подтверждение и подпись выполняются внутри кошелька.

Проверки: UiChecks `--derivation` проверяет отложенное заполнение после unlock,
точность суммы, отказ для malformed/чужого host/query и передачу URI через IPC.
MobileChecks проверяет общий мобильный интерфейс. Android intent filter
проверяется в собранном APK; реальный запуск по URI на телефоне проверяется
отдельно и не подразумевается результатами headless checks.

Откат: предыдущий EXE/APK (для Android downgrade может требовать специальной
процедуры — не удалять данные кошелька). Бот может вернуть универсальную
bip.to ссылку; семена, keystore и финансовые данные миграций не требуют.

Источники: [Android deep links](https://developer.android.com/training/app-links/create-deeplinks),
[Telegram InlineKeyboardButton](https://core.telegram.org/bots/api#inlinekeyboardbutton).
