# Подпись MinterWallet.exe

Без подписи Windows показывает при первом запуске «Система Windows защитила ваш компьютер». Подписанный файл
открывается без этого окна (SmartScreen доверяет издателю после набора репутации). Варианты:

## SignPath Foundation — бесплатно для открытых проектов

[SignPath Foundation](https://signpath.org) подписывает релизы проектов с открытой лицензией своим сертификатом
(издатель в свойствах файла — SignPath Foundation, проект указан в описании). Нужно подать заявку на сайте; после
одобрения в `release.yml` добавляется их GitHub Action, который отправляет собранный exe на подпись. Ограничения —
в их условиях: открытый код, сборка на GitHub Actions из тега, без вредоносного кода.

## Azure Trusted Signing — свой издатель, около $10 в месяц

Подпись именем владельца. Сейчас доступна организациям из ряда стран и частным лицам из США и Канады — проверьте
условия перед оплатой.

1. Создать в Azure учётную запись Trusted Signing, пройти проверку личности или организации, создать профиль
   сертификата (Public Trust).
2. Зарегистрировать приложение в Entra ID, выдать ему роль «Trusted Signing Certificate Profile Signer» на
   учётную запись, создать секрет клиента.
3. Добавить секреты в репозиторий (Settings → Secrets and variables → Actions):

   | Секрет | Что это |
   |---|---|
   | `AZURE_TENANT_ID`, `AZURE_CLIENT_ID`, `AZURE_CLIENT_SECRET` | приложение из шага 2 |
   | `AZURE_SIGNING_ENDPOINT` | адрес региона, например `https://weu.codesigning.azure.net/` |
   | `AZURE_SIGNING_ACCOUNT` | имя учётной записи Trusted Signing |
   | `AZURE_SIGNING_PROFILE` | имя профиля сертификата |

Как только `AZURE_CLIENT_ID` задан, `release.yml` подписывает exe сам; без него собирает неподписанный.

## Обычный сертификат подписи кода

OV-сертификат у удостоверяющего центра (от ~$200 в год, ключ — на токене или в облачном HSM). Подходит, если
другие варианты недоступны, но подпись в CI зависит от того, даёт ли центр облачный доступ к ключу.
