# Minter Wallet

Кошелёк для сети [Minter](https://www.minter.network/): Windows и Linux, один файл без установки, на русском и
английском.

*A desktop wallet for the Minter network (Windows, Linux): one self-contained file, keys stay on the device,
Russian and English interface (as the system, or chosen in the settings). MIT licence.*

## Что умеет

- **Ключи только на этом устройстве**, зашифрованные паролем (Argon2id, AES-256-GCM). Перед каждой подписью — окно
  подтверждения с полным адресом получателя, суммой, монетой и комиссией, и пароль.
- **Фраза восстановления без принуждения:** её можно записать или скопировать; проверка трёх слов — по желанию;
  при восстановлении фразу можно вставить как есть, с номерами и запятыми. Посмотреть и скопировать её можно позже,
  по паролю.
- **Несколько счетов:** новые адреса из той же фразы одной кнопкой, новые фразы, импорт фразы или приватного ключа,
  адреса только для просмотра.
- **Перевод и мультисенд** (до 100 получателей одной транзакцией), предупреждение о новом получателе.
- **Обмен:** монета выбирается из списка по тикеру или названию, цена и маршрут (пулы или резерв монеты)
  считаются сами; граница цены — из допустимого проскальзывания, дальше неё сеть сделку не проведёт.
- **Получить:** QR-код и адрес.
- **Суммы в долларах** — по курсу пула BIP/USDTE прямо из сети, без сторонних сервисов. Мелкие суммы показываются
  до первых значащих цифр (`0.00001234 BIP`, `$0.000412`), точная — в подсказке при наведении.
- **Адресная книга:** имена получателей, выбор из контактов при переводе.
- **Лимитные ордера и ликвидность:** продать по своей цене (кошелёк показывает допустимый диапазон), свои ордера и их
  отмена; добавить монеты в пул и вывести долю.
- **Чеки Minter:** выписать чек с паролем (текст и QR) и погасить полученный.
- **Стейкинг:** делегирование и вывод, поиск валидатора по ключу.
- **История:** транзакции расшифровываются самим кошельком из исходных байтов; через MinterGate — с момента запуска
  гейта, а более ранние — из обозревателя Minter (можно отключить).
- **Вид:** тема (тёмная, светлая, как в системе), адрес сплошной или группами по 4, у сумм — несколько знаков после
  точки или все.
- Смена пароля, автоблокировка, потолок gas price, сообщение о новой версии.
- **Языки:** русский и английский — как в системе или на выбор, без перезапуска. Перевод — в
  `src/MinterWallet/Translations.cs`; `py tools/i18n-missing.py` покажет строки без перевода, а проверка окна —
  экраны, где осталась кириллица.

## Откуда кошелёк берёт данные

По умолчанию — MinterGate `https://188.127.237.145:8851`: облегчённый клиент сети, который сам следует за блокчейном
и отвечает в формате API v2 ноды Minter. В настройках можно выбрать свою ноду (`http://127.0.0.1:8843`) или любой
другой адрес API v2.

Ответы источника (балансы, цены) кошелёк не проверяет, поэтому выбирайте тот, которому доверяете. Ключи источнику не
передаются: транзакция собирается и подписывается на устройстве, а всё, что показано в подтверждении, взято из
подписываемых данных. У адресов Minter нет контрольной суммы, поэтому перед переводом на новый адрес кошелёк просит
сверить его целиком. Начало и конец адреса выделены цветом, но сверять нужно и середину: мошенники подбирают адреса
с теми же первыми и последними символами.

### Если источник недоступен

Кошелёк пишет причину в строке состояния. Частые случаи:

- **Сертификат не подходит по дате** — на компьютере неверные дата, время или часовой пояс.
- **Система не доверяет сертификату** — устарели корневые сертификаты (Центр обновления Windows) или антивирус
  проверяет HTTPS и подменяет сертификат; отключите эту проверку для кошелька.
- **Соединение отклонено** — мешает системный прокси или VPN-клиент.
- **Нет ответа** — порт закрыт в вашей сети (офис, публичный Wi-Fi); попробуйте другую сеть.

Чтобы отделить сеть от кошелька, откройте в браузере `https://188.127.237.145:8851/v2/status`: если и там ошибка,
дело в сети или в компьютере. Можно добавить в настройках другой источник, например свою ноду.

Для диагностики проверку сертификата можно выключить у одного источника («Не проверять сертификат TLS» в
настройках). По умолчанию она включена. Пока проверка выключена, в боковой панели висит предупреждение, а ответы
источника может подменить посредник в сети; ключи и подпись при этом остаются на устройстве. Когда причина найдена,
проверку стоит включить обратно.

## Скачать

**[Последняя версия](https://github.com/xDilettante/MinterWallet/releases/latest)** — там же список изменений.
.NET ставить не нужно, всё нужное внутри файла.

| Система | Файл | Как запустить |
|---|---|---|
| Windows 10/11 x64 | `MinterWallet-<версия>-win-x64.exe` | запустить файл; если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» |
| Linux x64, большинство дистрибутивов | `MinterWallet-<версия>-x86_64.AppImage` | `chmod +x` и запустить |
| Debian, Ubuntu, Mint | `minter-wallet_<версия>_amd64.deb` | `sudo apt install ./minter-wallet_<версия>_amd64.deb`, затем «Minter Wallet» в меню |
| Linux x64 | `MinterWallet-<версия>-linux-x64` | просто файл: `chmod +x` и запустить |

Проверить, что файл скачался без искажений: `sha256sum -c SHA256SUMS.txt --ignore-missing` в Linux или
`Get-FileHash <файл>` в PowerShell — хеш должен совпасть со строкой в `SHA256SUMS.txt`. Файлы собирает GitHub Actions
из тега (`.github/workflows/release.yml`).

*Download: [latest release](https://github.com/xDilettante/MinterWallet/releases/latest) — the `.exe` for Windows,
an AppImage, a `.deb` or a plain file for Linux, and `SHA256SUMS.txt`.*

## Сборка

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0). Пользователю .NET не нужен: файл
самодостаточный.

```bash
dotnet publish src/MinterWallet -c Release -r win-x64 -p:PublishSingleFile=true -o artifacts/wallet-win-x64
dotnet publish src/MinterWallet -c Release -r linux-x64 -p:PublishSingleFile=true -o artifacts/wallet-linux-x64
```

Получится `MinterWallet.exe` (около 23 МБ) и `MinterWallet` для Linux x64. Файлы кошелька — в `%LOCALAPPDATA%\MinterWallet`
(Windows) или `~/.local/share/MinterWallet` (Linux); файл `portable` рядом с программой держит всё в папке `data`
рядом с ней. `--data DIR` — отдельная папка данных, `--self-test` — проверка файла без экрана.

## Проверки

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check.ps1
```

Сборка без предупреждений, проверки протокола (транзакции, подписи, комиссии, чеки, мнемоника) по фикстурам
из Go-ноды Minter v3.3.0 и официальных JS-библиотек, хранилище ключей, разбор API, очередь отправки, публикация
одним файлом и его самопроверка.

С локальной сетью — ещё сквозные прогоны: транзакции принимает и исполняет настоящая нода, кошелёк и его окно
(под Avalonia.Headless, со снимками экранов в `artifacts/ui-checks`) проходят создание, восстановление, переводы,
обмен, стейкинг и историю. Сеть поднимается в WSL (Ubuntu):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/devnet/build.ps1
wsl -d Ubuntu -u root -- bash tools/devnet/start.sh
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check.ps1 -Devnet http://WSL-IP:38843
```

`tools/generate-fixtures.ps1` пересоздаёт фикстуры протокола (нужны Go и Node.js). На GitHub то же самое делает
`.github/workflows/check.yml` на каждый коммит: Windows — сборка и проверки, Linux — с локальной сетью.
`tools/package-linux.sh` собирает AppImage и `.deb`, `tools/make-icons.py` — иконку.

## Устройство

| | |
|---|---|
| `src/Minter.Protocol` | протокол Minter: RLP, транзакции всех типов, подпись secp256k1, комиссии, чеки, BIP39/BIP32 |
| `src/MinterWallet.Core` | хранилище ключей, отправка с предпросмотром и очередью, история, настройки |
| `src/MinterWallet.Api` | клиент API v2 ноды Minter и MinterGate |
| `src/MinterWallet` | окно (Avalonia 12): экраны, тема, иконки |
| `tests/*` | проверки протокола, ядра кошелька и окна |
| `tools/oracle`, `tools/js-oracle` | эталоны для фикстур: Go-нода Minter и JS-библиотеки |
| `tools/devnet` | локальная сеть из одного валидатора на Go-ноде Minter v3.3.0 |
