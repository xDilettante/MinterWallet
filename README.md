# Minter Wallet

Кошелёк для сети [Minter](https://www.minter.network/): Windows и Linux, один файл без установки, на русском.

*A desktop wallet for the Minter network (Windows, Linux): one self-contained file, keys stay on the device,
Russian interface. MIT licence.*

## Что умеет

- **Ключи только на этом устройстве**, зашифрованные паролем (Argon2id, AES-256-GCM). Перед каждой подписью — окно
  подтверждения с полным адресом получателя группами по 4 символа, суммой, монетой и комиссией, и пароль.
- **Фраза восстановления без принуждения:** её можно записать или скопировать; проверка трёх слов — по желанию;
  при восстановлении фразу можно вставить как есть, с номерами и запятыми. Посмотреть и скопировать её можно позже,
  по паролю.
- **Несколько счетов:** новые адреса из той же фразы одной кнопкой, новые фразы, импорт фразы или приватного ключа,
  адреса только для просмотра.
- **Перевод и мультисенд** (до 100 получателей одной транзакцией), предупреждение о новом получателе.
- **Обмен:** монета выбирается из списка по тикеру или названию, цена и маршрут (пулы или резерв монеты)
  считаются сами; граница цены — из допустимого проскальзывания, дальше неё сеть сделку не проведёт.
- **Стейкинг:** делегирование и вывод, поиск валидатора по ключу.
- **История:** транзакции расшифровываются самим кошельком из исходных байтов.
- Тёмная и светлая тема, автоблокировка, потолок gas price.

## Откуда кошелёк берёт данные

По умолчанию — MinterGate `https://188.127.237.145:8851`: облегчённый клиент сети, который сам следует за блокчейном
и отвечает в формате API v2 ноды Minter. В настройках можно выбрать свою ноду (`http://127.0.0.1:8843`) или любой
другой адрес API v2.

Ответы источника (балансы, цены) кошелёк не проверяет, поэтому выбирайте тот, которому доверяете. Ключи источнику не
передаются: транзакция собирается и подписывается на устройстве, а всё, что показано в подтверждении, взято из
подписываемых данных. У адресов Minter нет контрольной суммы, поэтому перед переводом на новый адрес кошелёк просит
сверить его по группам символов.

## Сборка

Нужен [.NET SDK 10](https://dotnet.microsoft.com/download/dotnet/10.0). Пользователю .NET не нужен: файл
самодостаточный.

```bash
dotnet publish src/MinterWallet -c Release -r win-x64 -p:PublishSingleFile=true -o artifacts/wallet-win-x64
dotnet publish src/MinterWallet -c Release -r linux-x64 -p:PublishSingleFile=true -o artifacts/wallet-linux-x64
```

Получится `MinterWallet.exe` (около 23 МБ) и `MinterWallet` для Linux x64. Файлы кошелька — в `%LOCALAPPDATA%\MinterWallet`
(Windows) или `~/.local/share/MinterWallet` (Linux); файл `portable` рядом с программой держит всё в папке `data`
рядом с ней. `--data DIR` — отдельная папка данных, `--self-test` — проверка файла без экрана.

## Проверки

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check.ps1
```

Сборка без предупреждений, проверки протокола (транзакции, подписи, комиссии, чеки, мнемоника) по фикстурам
из Go-ноды Minter v3.3.0 и официальных JS-библиотек, хранилище ключей, разбор API, очередь отправки, публикация
одним файлом и его самопроверка.

С локальной сетью — ещё сквозные прогоны: транзакции принимает и исполняет настоящая нода, кошелёк и его окно
(под Avalonia.Headless, со снимками экранов в `artifacts/ui-checks`) проходят создание, восстановление, переводы,
обмен, стейкинг и историю. Сеть поднимается в WSL (Ubuntu):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/devnet/build.ps1
wsl -d Ubuntu -u root -- bash tools/devnet/start.sh
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/check.ps1 -Devnet http://WSL-IP:38843
```

`tools/generate-fixtures.ps1` пересоздаёт фикстуры протокола (нужны Go и Node.js).

## Устройство

| | |
|---|---|
| `src/Minter.Protocol` | протокол Minter: RLP, транзакции всех типов, подпись secp256k1, комиссии, чеки, BIP39/BIP32 |
| `src/MinterWallet.Core` | хранилище ключей, отправка с предпросмотром и очередью, история, настройки |
| `src/MinterWallet.Api` | клиент API v2 ноды Minter и MinterGate |
| `src/MinterWallet` | окно (Avalonia 12): экраны, тема, иконки |
| `tests/*` | проверки протокола, ядра кошелька и окна |
| `tools/oracle`, `tools/js-oracle` | эталоны для фикстур: Go-нода Minter и JS-библиотеки |
| `tools/devnet` | локальная сеть из одного валидатора на Go-ноде Minter v3.3.0 |
